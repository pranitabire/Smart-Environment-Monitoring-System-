# Smart Environment Monitoring System using IoT & Data Analysis (Raspberry Pi)

## 📌 Overview
An IoT-based environmental monitoring system designed to monitor temperature, humidity, and air quality in real time using Raspberry Pi and sensors.  
The system collects sensor data and sends it to the cloud for visualization and analysis.


## 🎯 Features
✔️ Real-time Environmental Monitoring  
✔️ Temperature & Humidity Detection  
✔️ Air Quality Monitoring  
✔️ Cloud Data Visualization  
✔️ Wireless Data Transmission  
✔️ Data Analysis using Graphs & Trends  


## 🛠️ Technologies Used
1. Raspberry Pi  
2. IoT  
3. ThingSpeak  
4. Python  
5. DHT11 Sensor  
6. MQ-135 Gas Sensor  


## ⚙️ Working
1. Sensors collect environmental data.  
2. Raspberry Pi processes the data.  
3. Data is transmitted through Wi-Fi.  
4. ThingSpeak displays graphs and trends in real time.  
5. Alerts can be generated for abnormal conditions.
